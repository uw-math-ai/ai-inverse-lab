### Concrete reuse finding: use Mathlib's measurable infinite-set predicate

`TauCeti/Probability/MarkovChain/Visits.lean`, new private theorem `measurableSet_setOf_infinite_setOf_eq`, approximately lines 165–172, re-proves measurability by expressing infinite visitation through every successive visit. Mathlib already exposes precisely the generic ingredients:

- `Mathlib/MeasureTheory/MeasurableSpace/Constructions.lean:1022`: `MeasurableSet.setOfPred_infinite : MeasurableSet {s : Set Nat | s.Infinite}`.
- The same file, `:952–958`: `Measurable.of_mem`, characterizing a measurable set-valued map by each membership predicate.
- The same file, `:928`: `Measurable.eq_const`; coordinate evaluation is measurable.

Pull the existing measurable predicate back along `w -> {n | w n = y}`. The proposed replacement expression, using the surrounding expected type, is:

```lean
MeasurableSet.setOfPred_infinite.preimage
  (Measurable.of_mem fun n => by
    simpa only [Set.mem_ofPred_eq] using
      (measurable_pi_apply n : Measurable fun w : ℕ → α => w n).eq_const y)
```

This typed expression was subsequently checked by Lean against the pinned Mathlib, without errors or warnings. The initial unannotated expression did not elaborate; the explicit coordinate-map type and membership simplification above resolve inference. It avoids rederiving measurability through successive visits; consumers may use the existing Mathlib composition directly or retain a short local helper.

There is a second simple reuse opportunity in the newly expanded almost-sure proof: `hS` hand-proves measurability of implication by a set equality and union. With `hH` and `hI` already available, use `hH.imp hI` (`MeasurableSet.imp`) instead. This point is already raised in the existing external review; there is no need to post it again.

## Why the generalized mathematics is valid

The PR does not quietly replace finite measures with sigma-finite measures. The inspected APIs genuinely support arbitrary initial measures:

1. `TauCeti/Probability/Process/MarkovChain.lean:191`, `Measure.markovChainLaw_eq_comp`, has **no** `[IsFiniteMeasure nu]` or `[SFinite nu]` hypothesis. It identifies the path law with `kappa.markovChainKernel` integrated against `nu`.
2. Mathlib `MeasureTheory/Measure/GiryMonad.lean:242`, `Measure.bind_apply`, requires a measurable target event and an a.e. measurable measure-valued map, without finiteness of the initial measure. Kernels supply the needed measurability.
3. Mathlib `Probability/Kernel/Composition/MeasureComp.lean:59`, `Measure.ae_comp_of_ae_ae`, has no finiteness restriction. It requires measurability of the property event, which is why the PR establishes the entrance/infinite-visit events before mixing.
4. Mathlib `MeasureTheory/Integral/Lebesgue/Add.lean:433`, `lintegral_mul_const`, uses measurability of the integrand, without requiring a finite measure or a finite constant. Thus mixing the fixed-start scaled law remains legitimate with infinite initial mass.

For `markovChainLaw_restrict_map_successiveVisit_eq_smul`, the PR proves the identity at each Dirac start using the finite strong Markov theorem and integrates that identity. The visit event and stopped shift are measurable. This is a correct mixture argument.

For recurrence/transience almost-sure statements, simply dropping finiteness from the old proofs would be invalid: equality of infinite event masses cannot establish equality almost everywhere, and infinity times a vanishing sequence need not converge to zero. The PR correctly keeps those arguments inside a local finite-measure `key`, applies them to Dirac starts, and then mixes the measurable almost-sure property or null event. No arithmetic with an unjustified `infinity * 0` limit is used.

The generalized geometric-tail, visit-count integral, and Green identities are extended nonnegative identities. They remain meaningful when both sides are infinity. If the first-entry mass is zero and the return Green function is infinity, ENNReal's `0 * infinity = 0` matches zero occupation almost everywhere. If initial mass is infinite, the mixture argument rather than subtracting two infinite masses supplies the proof.

The downstream `omit [IsFiniteMeasure nu] in` changes are appropriate for almost-sure transfer. Expected-frequency limits and transient transition-mass limits still retain finiteness where bounded convergence or finite total Green mass requires it. No claim that those analytic limits extend to arbitrary measures was introduced.
