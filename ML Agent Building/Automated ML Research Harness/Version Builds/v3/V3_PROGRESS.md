## Validation and repairs

The existing V1/V2 baseline was **36 tests passed in 194.931 seconds** before implementation; see `baseline_tests.log`.

Implementer tests include focused scientific/evidence checks, execution certification/reservation checks, knowledge/evaluation checks, and small end-to-end software fixtures. The final focused run of the two implementation runtime tests passed in **15.176 seconds** after the random-search/shared-computation and resume repairs. They verify complete studies, exact exported-model certification, reproducible report rebuilding, resume without extra exposure, lossless random-search parent/candidate provenance, and actual shared prediction reuse. Resume also rejects a changed compiled specification, restores accounting, continues experiment IDs beyond the persisted ledger, and recovers a persisted final result after a simulated reporting interruption without changing model bytes or accessing the holdout again. Temporary package stores are used by current fixtures; generated default V3 package caches are ignored by Git.

Independent review identified and drove repairs for:

- Scalar uncertainty being omitted and an unrelated paired interval being accepted.
- Unregistered effective-method factors being accepted.
- Missing implicit scientific evidence failing to block study completion.
- Critic objections arriving after verdict calculation, unrelated evidence/revisions resolving objections, and overly broad synthesis scope.
- Duplicate-control deduplication interacting incorrectly with DAG prerequisites.
- Immutable arm identity, merged claim study IDs, frozen snapshot restoration and package-route integration.
- Final exposure attempt marking and reservation release on failed admission.

The independent reviewer's final full suite passed **93 tests in 201.504 seconds** with exit code 0, followed by the focused resume/runtime check above. The reviewer owns the authoritative regression logs, acceptance review and outstanding findings in [V3_TEST_RESULTS.md](V3_TEST_RESULTS.md). Earlier full-suite counts in that file describe intermediate source snapshots; the final labeled run is authoritative.

## Delivery pointers and explicit limits

See [V3_ARCHITECTURE.md](V3_ARCHITECTURE.md), [V3_CHANGELOG.md](V3_CHANGELOG.md) and [V3_USAGE.md](V3_USAGE.md) for implementation details, preservation notes, configuration and commands. The example is [specs/v3_example.yaml](../../specs/v3_example.yaml). Running it is future user research work; it was compiled for configuration validation only.

The remaining limits are extension or empirical-evaluation work: verified mathematical proofs, general mechanism/solver/surrogate-specific executable adapters, general shared fitted-state/trajectory reuse, forced preemption of arbitrary Python specialist callbacks, comprehensive empirical literature coverage, and a real independent-instance discovery/transfer campaign. Unsupported requests remain deferred, incomplete or untestable; they do not receive fabricated evidence or certification. V1/V2 pipelines and historical artifact/report formats remain available. Historical runs, ablation outputs and the user goal file were not rewritten.
